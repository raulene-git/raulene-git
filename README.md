## Fieldnotes: a working SharePoint intranet

[![Demo: a consignment is edited in the SharePoint list and the Dispatch Board updates to match](https://raw.githubusercontent.com/raulene-git/spfx-logistics-hub/main/docs/media/dispatch-board-live-demo.gif)](https://github.com/raulene-git/spfx-logistics-hub)

*A consignment is edited in SharePoint and the dispatch board updates to match. Recorded on a live Microsoft 365 tenant.*

Fieldnotes Logistics is a made-up haulage company, but the intranet is real and running. I designed and built it end to end:

- **A live dispatch board.** Every consignment and where it is, with one-click filters for exceptions and late deliveries, fed straight from a SharePoint list.
- **Spreadsheet imports.** The ops team keeps working in Excel. They drop in the weekly sheet, the importer matches the columns, flags bad rows in plain words, then adds or updates the list.
- **An IT helpdesk.** Staff raise tickets from simple forms that set the priority for them. IT gets a queue with statuses, assignments and a worklog. SharePoint permissions keep each person's tickets private.
- **A homepage that keeps itself current.** News appears as soon as it's published, and new starters appear as soon as their account is created in Entra ID.

Eleven SharePoint Framework web parts in one package, with automated tests and a build pipeline. → [**See the repo, screenshots and how it's built**](https://github.com/raulene-git/spfx-logistics-hub)
